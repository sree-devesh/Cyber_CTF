# Cyber CTF - TOCTOU

## How to Run

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Start the server:
```bash
cd TOCTOU/demo
python3 server.py
```

3. Run the exploit:
```bash
cd TOCTOU/demo
python3 exploit.py
```

---

## Where to Access

- **Shop:** [http://localhost:8080](http://localhost:8080)
- **Orders:** [http://localhost:8080/orders](http://localhost:8080/orders)
- **Admin Panel:** [http://localhost:8080/admin](http://localhost:8080/admin)

---

## How to Reset

- Click the **↺ Reset** button in the navigation bar, or
- Visit [http://localhost:8080/reset](http://localhost:8080/reset)
